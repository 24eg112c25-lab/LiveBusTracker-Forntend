Core System Capabilities

Engineered with high precision for academic demonstration and real-world deployment

📍

Interactive Leaflet & OSM Map

Real-time vehicle position tracking on OpenStreetMap with directional orientation arrows, route paths, sequence stop pins, and instant ETA calculations.

⏱️

Hardware-Free GPS Simulation

Built-in mathematical simulator interpolates smooth bus movements between consecutive route waypoints with realistic dwell times at each stop without needing GPS hardware.

🛡️

Full Fleet & Route Admin CRUD

Manage buses, routes, and stops effortlessly. Features an interactive click-on-map coordinate picker to place new stops without manual GPS coordinate lookups.

📐

Haversine Proximity & ETAs

Dynamic calculations of remaining distances and estimated arrival times (ETAs) based on realistic vehicle velocities and stop progression.

🔍

Transit Route Finder

Search suitable routes between any origin and destination stops across the campus transit network with instant distance breakdowns.

📦

Single-Artifact Deployment

Self-contained Spring Boot application serving both REST API services and responsive static frontend assets simultaneously from embedded Tomcat.
